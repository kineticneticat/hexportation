# Complex Hex

... is an addon for Hexcasting that adds item, fluid and energy transportation alongside basic filtering options. \
[wiki](https://complexhex.hexxy.media)

## features
Conduits that allow two positions & directions to be linked with an iota.
Items can be pulled/pushed from an inventory at either end, or the items can be dropped on the ground/picked up.
Fluids can be pulled/pushed to a tank, or the fluid can be placed in-world or collected.
Energy can be pulled/pushed to energy,, storage
Items & Fluids use the fapi inventory api and so should be compatible with most (sensible) mods
Energy uses the Tech Reborn api which is also compatible with most mods i think
Conduits also allow for peeking at the contents of a container at either end, and then dictating what items and how many of each should be removed.
